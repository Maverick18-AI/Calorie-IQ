## Remaining limits and physical acceptance

- Physical iPhone 16 Safari/Home Screen, camera barcode recognition, VoiceOver,
  cellular performance and low-memory behaviour are still untested.
- OFF name search remains externally unreliable. Its app-usage registration and
  preferred browser identification need owner follow-up. Chromium drops custom
  User-Agent; public app name/version query fields remain. No third-party form,
  contact message or new credential was submitted for this release.
- USDA Branded and CNF nutrition remain deferred; this release adds no database
  beyond the three reviewed USDA sets. USDA reference values do not guarantee
  manufacturer-label values. 169 records retain quality warnings.
- Offline details exist only for previously cached shards; browser eviction and
  the bounded cache can remove them. The full database is not promised offline.
- USDA remains CC0 and OFF remains ODbL/DbCL, with separate data and provenance.
  No paid infrastructure, private browser key, analytics, ads or subscriptions.

and uncached USDA details. Use Settings to check for an update if an old build
remains visible. Do not clear Safari storage merely to update the app.
